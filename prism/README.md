# Prism

Synced reminders that ring on every device at once — a small, modern, Claude-themed
reminder app for **Android (Vivo V27)** and **macOS (M4)**.

Schedule a task once on either device → it appears on both → each device fires its
own local notification **with sound** at the time you set. Because phones and Macs
keep their clocks NTP-synced, "3:00 PM" rings on both within about a second. No
always-on server of your own; cross-device sharing rides on a free Firebase
Realtime Database over plain HTTPS.

- **Look:** warm ivory/charcoal canvas, coral accent, frosted translucent "crystal"
  cards and option chips.
- **Light by design:** ~1,400 lines of Dart, six small dependencies, no heavyweight
  state-management or backend code. One Dart codebase compiles to both a native
  Android app and a native macOS app.

## How it's put together

```
prism/
├── lib/                      # all the app code (the only hand-written source)
│   ├── main.dart             # entry point + global app state
│   ├── theme.dart            # Claude palette + "crystal" glass constants
│   ├── models/reminder.dart  # the Reminder data model
│   ├── services/             # notifications · local storage · cloud sync
│   ├── state/app_state.dart  # single source of truth, wires it all together
│   ├── widgets/              # frosted glass card, chips, gradient background
│   └── screens/              # home · add/edit · settings
├── platform_overlay/         # native bits we override (permissions, entitlements)
├── tool/setup.sh             # regenerates android/ + macos/ then applies the overlay
├── FIREBASE_SETUP.md         # 10-minute one-time sync setup
└── pubspec.yaml              # dependencies
```

The `android/` and `macos/` folders are **not** committed — they're generated by
`tool/setup.sh` (locally and in CI) and then patched with `platform_overlay/`, which
adds: Android notification + exact-alarm + boot permissions, and macOS sandbox
network/entitlement keys so cloud sync works in a release build.

## Getting the app onto your devices (auto-build — no tools on your end)

Every push to `prism/**` triggers the **Prism build** GitHub Action
(`.github/workflows/prism-build.yml`), which builds the Android APK and the macOS
app and publishes them to a single, always-current **`prism-latest`** release.

### Download links (after the first build finishes, ~5–10 min)

On the repo: **Releases → `Prism — latest build`**, or directly:

- **Android:** `…/releases/download/prism-latest/Prism.apk`
- **macOS:** `…/releases/download/prism-latest/Prism-macOS.zip`

> Prefer not to publish a release? The same two files are also attached to each
> Actions run under **Actions → Prism build → Artifacts** (`prism-android-apk`,
> `prism-macos-app`).

### Install on the Vivo V27

1. Open the `Prism.apk` link on the phone (or transfer the file over).
2. Tap to install. FunTouch OS will warn about installing from this source —
   allow it for your browser/Files this once.
3. Open Prism, and when asked, **allow notifications** and **allow exact alarms**.
4. Do the one-time battery fix below so reminders aren't killed in the background.

### Install on the M4 Mac

1. Download `Prism-macOS.zip`, double-click to unzip → `Prism.app`.
2. Drag `Prism.app` into **Applications**.
3. The app is **unsigned** (no paid Apple Developer account), so the first launch:
   **right-click → Open → Open**. (After that it opens normally.)
   If macOS still blocks it: **System Settings → Privacy & Security → Open Anyway**.
4. Allow notifications when prompted (or **System Settings → Notifications → Prism**).

### Then: turn on sync (once)

Follow **[FIREBASE_SETUP.md](FIREBASE_SETUP.md)** — ~10 minutes, free, no card. Paste
the same Database URL + sync code on both devices and you're done.

## Vivo V27 — keep reminders firing (one-time)

FunTouch OS aggressively closes background apps, which can silence scheduled
reminders. On the Vivo:

- **Settings → Battery → High background power usage →** enable **Prism**.
- **Settings → Apps → Auto-start manager →** allow **Prism**.
- Open **Recents**, long-press **Prism → lock it** (padlock) so it isn't cleared.

(These same steps are listed inside the app under Settings.)

## Building it yourself (optional)

If you'd rather build on the Mac instead of downloading:

```bash
# one-time: install Flutter — https://docs.flutter.dev/get-started/install/macos
cd prism
bash tool/setup.sh                 # generates android/ + macos/, applies overlay, pub get

flutter run -d macos               # run the Mac app live
flutter build macos --release      # build the Mac .app
flutter build apk --release        # build the Android APK (with the phone or an emulator)
```

Building locally also avoids the macOS "unsigned app" warning, since it's signed
with your own machine.

## Notes & honest limitations

- **Sync model:** newest edit wins (each reminder carries an `updatedAt`). Editing
  the *same* reminder on both devices within the same few seconds while offline is
  the only case that can lose an edit — fine for normal use.
- **Security:** the sync code is the only secret (see FIREBASE_SETUP.md). Long random
  code = safe enough for personal reminders; ask me if you want signed-in auth.
- **Same-second ringing** relies on both devices having correct network time (they do
  by default). There's no central "fire now" signal — each device rings itself.
